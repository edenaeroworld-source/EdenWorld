# Marca EDENWORLD

- `edenworld-logo-original.png` — logotipo original fornecido pela direção do projeto (1293×1216, RGBA).

Arquivos derivados usados pelo jogo (gerados a partir do original com recorte das bordas
transparentes e redimensionamento Lanczos):

| Arquivo | Uso |
| --- | --- |
| `public/assets/ui/logo-edenworld.webp` (960 px) | Menu principal em telas grandes |
| `public/assets/ui/logo-edenworld-480.webp` (480 px) | Menu em telas pequenas, tela de carregamento |
| `public/icons/icon-512.png`, `icon-192.png` | Manifesto do aplicativo web |
| `public/icons/apple-touch-icon.png` | Atalho na tela inicial (iOS) |
| `public/icons/favicon-64.png`, `favicon-32.png` | Ícone da aba do navegador |

Os ícones aplicam o logotipo sobre um gradiente radial aqua (identidade Frutiger Aero do Éden).
